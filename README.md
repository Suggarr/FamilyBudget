# FamilyBudget

FamilyBudget — приложение для учёта личных и семейных финансов. Сейчас пользовательский интерфейс работает в Telegram: можно вручную записывать доходы и расходы, вести семейную копилку, просматривать историю и отчёты. Расход также можно создать из фотографии чека: локальная модель распознаёт данные, после чего пользователь проверяет результат и выбирает категорию.

API запускает Telegram-бота в том же .NET-процессе. `docker-compose.yml` поднимает только PostgreSQL и Ollama, **не API**.

## Что уже есть

- Регистрация через Telegram, создание семьи и присоединение по приглашению.
- Доходы, ручные расходы, баланс пользователя и семейная копилка с пополнением и снятием.
- Распознавание чека по фото или изображению, отправленному файлом без сжатия; сохранение чека и расхода после подтверждения категории.
- История операций и чеков, семейные отчёты и подписка на отчёты в Telegram.
- `POST /api/auth/register` для создания локального аккаунта по email и паролю.

Локальный вход, выдача JWT, обновление токенов и авторизация остальных API-методов **ещё не завершены**. Регистрация по email пока не даёт доступ к функциям Telegram-бота и не возвращает токен.

## Требования

- .NET SDK 8 или новее, способный собирать проекты `net8.0`.
- Docker с Compose для PostgreSQL и, если нужны чеки по фото, Ollama.
- Токен собственного Telegram-бота.
- Для текущей конфигурации Ollama — работающая поддержка GPU в Docker: сервис содержит `gpus: all`.
- Для миграций — установленный `dotnet-ef` (проект использует EF Core 9).

## Быстрый запуск

Команды ниже выполняются из корня репозитория, где лежит `docker-compose.yml`.

1. Создайте `.env` из шаблона:

   ```powershell
   Copy-Item .env.example .env
   ```

   Замените `POSTGRES_PASSWORD` и `TELEGRAM_BOT_TOKEN` на свои значения. Укажите **тот же** пароль в `ConnectionStrings__FamilyBudgetDbContext`. При изменении `POSTGRES_PORT` измените и `Port` в строке подключения. Не добавляйте `.env` в Git.

2. Запустите базу:

   ```powershell
   docker compose up -d postgres
   ```

3. Если нужны чеки по фото, запустите Ollama:

   ```powershell
   docker compose up -d ollama
   docker compose logs -f ollama
   ```

   При первом старте Compose скачает модель из `OLLAMA_MODEL`. Это может занять время и место на диске. Команда `docker compose up -d ollama` запускает только Ollama — PostgreSQL нужно запускать отдельно. Проверить модель можно так:

   ```powershell
   docker exec familybudget-ollama ollama list
   ```

4. Примените миграции:

   ```powershell
   Set-Location FamilyBudget
   dotnet ef database update --project FamilyBudget.Persistence --startup-project FamilyBudget.Persistence
   ```

5. Запустите API и бота:

   ```powershell
   dotnet run --project FamilyBudget.API --launch-profile https
   ```

   В режиме Development Swagger доступен по адресу `https://localhost:7154/swagger`. Если запускаете через Visual Studio, стартовым проектом выберите `FamilyBudget.API`. Откройте своего бота в Telegram и отправьте `/start`.

Запускайте только **один экземпляр** API с этим токеном бота: оба экземпляра будут пытаться получать одни и те же Telegram-обновления.

## Настройки

Пример всех необходимых для текущего запуска переменных находится в [`.env.example`](.env.example):

| Переменная | Для чего нужна |
| --- | --- |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_PORT` | Создание PostgreSQL-контейнера и проброс порта на хост. |
| `ConnectionStrings__FamilyBudgetDbContext` | Подключение .NET-приложения и EF CLI к базе. При запуске приложения на хосте используйте `Host=localhost` и опубликованный порт. |
| `TELEGRAM_BOT_TOKEN` | Токен бота; без него API сейчас не стартует. |
| `OLLAMA_BASE_URL` | Адрес Ollama для .NET-приложения; при запуске API на хосте — `http://localhost:11434/`. |
| `OLLAMA_MODEL` | Модель распознавания чеков; Compose скачает её при первом старте Ollama. |
| `OLLAMA_CONTEXT_LENGTH` | Размер контекста модели в Compose. |

Загрузчик `.env` ищет файл в текущем каталоге и родительских каталогах. Уже установленные переменные окружения имеют приоритет. Значения `JwtOptions` пока не подключены к приложению: JWT находится в разработке, поэтому JWT-переменные сейчас не требуются для запуска.

## Как пользоваться

В Telegram отправьте `/start` и следуйте кнопкам для создания семьи или вступления по приглашению. В главном меню доступны расход, доход, отчёт, семья, история, чеки и копилка. Для ручного расхода используйте «➕ Расход». Для чека выберите «➕ Расход» → «📷 По фото чека», затем отправьте фото либо изображение как файл (JPG, PNG или WebP). После распознавания проверьте суммы и позиции и выберите категорию, чтобы подтвердить расход.

Распознавание выполняется в фоновом обработчике очереди; бот может принимать другие сообщения, пока чек обрабатывается. Результат модели может быть неточным. Если проверка сумм не пройдена, чек и расход не сохраняются. Сейчас расходы ведутся в BYN; чек в другой валюте нельзя считать автоматически конвертированным.

Для проверки локальной регистрации используйте Swagger: `POST /api/auth/register` с полями `displayName`, `email`, `password`, `confirmPassword`. В ответ приходит `accountId`; вход через API пока не реализован.

## Структура решения

| Проект | Ответственность |
| --- | --- |
| `FamilyBudget.Core` | Доменные модели, правила и интерфейсы репозиториев/внешних сервисов. |
| `FamilyBudget.Application` | Сценарии использования, сервисы и DTO. |
| `FamilyBudget.Persistence` | EF Core, PostgreSQL, конфигурации, репозитории и миграции. |
| `FamilyBudget.Infrastructure` | Интеграция с Ollama, хеширование паролей, загрузка окружения. |
| `FamilyBudget.Presentation.Telegram` | Telegram-обработчики, клавиатуры и фоновые задачи. |
| `FamilyBudget.API` | HTTP-контроллеры и точка запуска всех частей. |

Файл решения: `FamilyBudget/FamilyBudget.sln`. Проверка сборки из папки решения:

```powershell
dotnet build FamilyBudget.sln
```

## Если что-то не работает

- **API не стартует:** проверьте `TELEGRAM_BOT_TOKEN`, строку подключения и доступность PostgreSQL. Бот запускается вместе с API.
- **Бот не отвечает на `/start`:** проверьте вывод API и убедитесь, что с тем же токеном не работает второй экземпляр бота.
- **Чек долго распознаётся или Ollama отвечает с ошибкой:** проверьте `docker compose logs -f ollama`, наличие модели через `ollama list`, поддержку GPU, свободную память и значение `OLLAMA_CONTEXT_LENGTH`.
- **БД пуста после пересоздания контейнера:** данные находятся в именованном volume `familybudget_postgres_data`. `docker compose down` сохраняет volume; `docker compose down -v` удаляет его вместе с данными. Не используйте `-v`, если нужно сохранить базу.

Пароли, токен Telegram и будущий секрет подписи JWT не следует записывать в README, исходный код или коммиты. Для собственных значений используйте `.env` либо переменные окружения.
